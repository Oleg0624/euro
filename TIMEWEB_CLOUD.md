# Перенос сайта «ЕВРОПА ПРОМ» в Timeweb Cloud

Пакет подготовлен для запуска в **Timeweb Cloud App Platform** через Dockerfile.
Сайт не использует базу данных и секретные переменные окружения.

## Содержимое пакета

- исходный код сайта;
- `Dockerfile` для сборки и запуска;
- `.dockerignore` для компактного контейнера;
- проверка состояния сайта по адресу `/`;
- публичные изображения и метаданные сайта.

## Рекомендуемый способ переноса

1. Распакуйте архив и загрузите его содержимое в новый репозиторий GitHub,
   GitLab или Bitbucket. `Dockerfile` должен остаться в корне репозитория.
2. В панели Timeweb Cloud откройте **App Platform** и создайте приложение.
3. В качестве типа приложения выберите **Dockerfile**.
4. Подключите созданный репозиторий и выберите его основную ветку.
5. Поле «Путь к директории проекта» оставьте пустым.
6. Переменные окружения добавлять не требуется.
7. Путь проверки состояния указывать не требуется: он уже задан в Dockerfile.
8. Выберите регион и конфигурацию сервера, затем запустите деплой.
9. После успешного запуска откройте технический домен, показанный на дашборде.

Контейнер слушает `0.0.0.0:8080`. Timeweb Cloud определит внутренний порт по
инструкции `EXPOSE 8080` и настроит внешний HTTPS-доступ автоматически.

## Подключение собственного домена

После успешного деплоя добавьте домен в настройках приложения и создайте у
регистратора DNS-записи, которые покажет панель Timeweb Cloud. Дождитесь
обновления DNS и выпуска SSL-сертификата, прежде чем отключать старую версию.

## Безопасный порядок переключения

1. Сначала разверните и проверьте сайт на техническом домене Timeweb Cloud.
2. Подключите основной домен, не удаляя старую площадку.
3. Переключите DNS и дождитесь распространения записей.
4. Проверьте главную страницу, калькулятор, телефон и почтовые ссылки.
5. Отключайте прежнюю площадку только после проверки нового домена.

## Локальная проверка через Docker

```bash
docker build -t evropa-prom .
docker run --rm -p 8080:8080 evropa-prom
```

После запуска сайт будет доступен по адресу `http://localhost:8080`.

## Обновление сайта

Внесите изменения, сохраните их в подключённой ветке и отправьте в репозиторий.
При включённом автодеплое App Platform автоматически соберёт новую версию.
