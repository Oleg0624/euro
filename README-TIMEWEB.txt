ЕВРОПА ПРОМ — статическая версия для Timeweb Cloud

1. Распакуйте архив и загрузите его содержимое в отдельный Git-репозиторий.
2. В Timeweb Cloud создайте приложение App Platform.
3. Выберите: Frontend → HTML/CSS/JS.
4. Подключите репозиторий с содержимым этого архива.
5. Путь к директории проекта оставьте пустым: index.html находится в корне.
6. Команда сборки, Dockerfile, Node.js и переменные окружения не требуются.
7. Запустите деплой.

Важно: загружать нужно именно содержимое архива, чтобы index.html оказался
в корне репозитория, а не внутри дополнительной вложенной папки.
